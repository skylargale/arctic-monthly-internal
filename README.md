# arctic-monthly-internal

Code accompanying [Gale et al. (2026b)](https://essopenarchive.org/doi/full/10.22541/essoar.15002817/v1) (preprint).

## Repository Contents

### Notebooks

- `download_era5.ipynb`  
  Notebook adapted from the Climate Data Store API workflow to download ERA5 surface data.

- `Make_Figures.ipynb`  
  Code used to generate all manuscript figures and supplementary material.

## Setup

This repository was developed using a standard Python environment with commonly used scientific Python libraries (e.g., NumPy, Xarray, Matplotlib, SciPy, and Cartopy).

Users may install dependencies manually within their preferred Python environment.

## Data Availability

Processed data used in this repository is available on Zenodo:

- Code archive: [https://zenodo.org/records/20040166](https://zenodo.org/records/20040166)
- Data archive: [https://zenodo.org/records/18842089](https://zenodo.org/records/18842089)

File paths within notebooks may need to be modified depending on local data storage locations.
